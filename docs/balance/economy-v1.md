# 村庄经济 v1 · 银金钱包

2026-10-23，任务127。玩家授权实现：100银币=1金币，钱包自动换算；同步调整任务、种植、养殖与投资价格。以下是已落地的第一版候选，长期节奏仍待玩家试玩反馈。

## 计价与存档

服务端以整数银币结算，`inventory.gold` / `costs.gold` / `reward.gold` 保留原稳定ID。只有一个余额，没有兑换手续费和独立金币库存。99→99银，100→1金，245→2金45银；不足整金币时自动找零，大余额带千分位并保留零头。HUD、商店、装备、牧场、人物档案、材料/回礼和错误报价共用格式。

旧存档数值原样保留，不乘100、不清零、不追发奖励；旧数值统一解释成银币。常见商品数值保持原尺度，本文列出的重新定价统一生效，因此它是一轮公开的经济重平衡，并非保证所有旧商品购买力不变。增加`economy_version=1`幂等标记。旧已接/已领渐进任务使用`quest_contracts_v2.json`固定旧条款；更早任务继续原v1契约。旧160现金回礼依约结算，不额外领新版援助。未接任务使用新规则。

## 新手资金链

开局20银 → 安家+10 → 四萝卜交付+16 → 建房-30 → 建房回礼+8 → 牧场回礼+12 → 首剑-24 = **余12银**。木板任务仍供应建房6木材/3石料。建房回礼另给3饲料和一次基础禽舍完整施工、首只小鸡领养援助。玩家在原建造/购买界面确认领取，服务端按0成本报价并原子消费资格；后续小鸡60银、禽舍扩建2金40银。已有相应住所或鸡的旅程不重复取得这项资格；已领取任务不能再次发援助。失败/重复请求不重复扣款或发放。

首次金币是正常余额达到100银的显示结果，不是任务锁或可重复奖励。按余12银、6块田、只种萝卜、每轮重新买种且不作其他收支，三轮净增108银后余1金20银；这只是明确假设下的算账，不能当成实际游玩耗时。睡眠可推进生产，因此不把“游戏日”当成现实等待。大田仍需要种子、体力和逐块操作，未另加土地配额。

## 消费目标与其他收入

- 小屋/工坊/图书馆升级：1→2为30银+6木3石，2→3为1金20银+12木6石。
- 首剑24银；加固短剑1金20银（图纸40银）；弹簧长矛/微光短杖1金50银（图纸50银）。其他装备沿目录原数值以银金显示，材料/制造和使用门槛保持。
- 禽舍80/240/560银，畜棚260/600/1200银，马厩400/800/1400银；均保留各级材料成本。
- 木材订单18银、石料20银、四萝卜24银；仍按现实日限次。后者高于直接出售，作为有限委托溢价。供应商支线回礼降为24银。
- 远行船票6银、旅店8银、热食3银、便携菜汤8银，家中睡眠/短休免费；旅途打工保留缺钱退路。
- 洞穴现有掉落、首胜、图纸和现实成长点互不兑换；不改现实委托5点额度。无新货币、耐久、税费或玩家交易市场。
