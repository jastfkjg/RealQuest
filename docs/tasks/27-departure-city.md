# 27 · 离村与城市落脚点

目标：保留旧存档，在取得洞穴魔法石、达到启门魔法等级并永久开启离村石门后，接通告示板接信 → 村外渡口 → 渡河 → 翻越山脉 → 苔桥城交信 → 付费住宿 → 返乡交付的完整链路。

## 开发路线衔接（2026-10-16 更新）

本任务的旅行与住宿实现候选及证据保留。按最新确认的[玩法设计](../game-design.md)与[开发顺序](../../TODO.md)，怪物仅在主动进入的洞穴等特定战斗地点出现，普通道路与生活区安全。武器可购买或打造，数值有区别；打造须建造等级与配方指定的科学或魔法等级，购买不沿用制造资格。

完整第一章验收链为：调查封路石门 → 村庄经营与成长、购武器或等级打造 → 洞穴探索并取得指定Boss魔法石 → 达到启门魔法等级 → 石门前确认并永久开门 → 接信与准备 → 任选修桥或乘船 → 翻山 → 城市交信与住宿 → 可返家。成长与探索可交错；[村庄成长数值v1候选](../balance/village-progression-v1.md)细化为5层洞穴、160生命Boss首次保底1枚魔法石、魔法3级启门，价格／配方／体能准备与现实成长时间均有候选账目，尚待实现与试玩。

石门位于通往渡口的共同出口，桥／船不能绕过；开启须同时校验魔法石取得来源、当前持有与魔法等级，科技主修也须达到最低启门魔法。魔法石不能买来替代、出售或用于普通配方；开启一次嵌石、永久通行，失败不扣石、重试不重复消耗，返乡与再次远行不重打Boss。已有离村／抵城进度的旧存档不重新封路、撤奖或清空记录，保留补做入口；现有两座村内桥与生活地点不受影响。

本次路线调整仅同步文档，未修改本任务代码。新规则取代旧护路委托与“魔法0级即可离村”的规划，现实委托仍按原来源与每日5点规则提供成长；购买武器可替代制造投入，不额外强制全部属性同步升级。现有旅行实现须另行接入并验证石门前置，单独跑通旅行不能视为新版第一章整体验收完成。城市进阶任务安排在送信与落脚之后，不作为入城或首晚住宿条件。

## 实施计划

1. 服务端增量添加地图、离村任务和通行规则。修桥（木板 6、石料 4；建造 1 级，或额外 10 金币请工匠）与船票（单程 6 金币）并行。绳索 6 金币；翻山消耗当前体力 60、游戏时间 180 分钟；返程体力 20、120 分钟。所有耗时操作必须在 01:00 前结束。
2. 增加渡口、山路、苔桥城及灯穗旅店。送信补贴 12 金币；当晚房费 8 金币，床上睡醒仍在旅店。旅途小憩、补给和每日帮工提供准备与缺钱补救路线。昏倒规则仍返家。
3. 沿用 Hearthwood 图像、比例、亚麻纸面和木框。新增阿渡（草帽、靛蓝短衫、船桨）与岚姨（银发发髻、绿披肩、赭色围裙），独立原创形象、头像和静态场景帧；不冒充已有日程居民。
4. 连通任务追踪、跨地图方向标记、远行地图和住宿选择，验证失败、重试、存档兼容与日夜系统回归。

视觉主张：新区域像原村庄沿山水延伸出的相邻地方，地面、树木和家具复用已审计像素素材，地理轮廓由代码绘制；文字与操作保留现有 DOM 组件。
内容主张：每个关口只展示眼前可做的事及明确的代价；首城是可以交接、住宿和返家的落脚点。
交互主张：地图只标方向，实际通行必须走近关口并确认；服务器核价和扣除，日期与地点校验阻止过期请求。

## 旅行段实现记录（本轮代码，2026-10-16）

这里记录旅行段实现时的独立链路，不覆盖上方后续细化的洞穴、武器与石门规划。当前代码以交付安家任务解锁村外路牌；魔法石与启门等级共同开启石门的条件尚未实现，不能将下方旅行验证视为新版第一章的整体验收。既有实现记录与证据保留，本次文档调整未重跑这些测试。

已实现：

- 「山那边，灯火正亮」主线：告示板接信 → 东行路牌 → 苇风渡口 → 渡河 → 苍脊山脉 → 苔桥城南门街 → 灯穗旅店交信、订房、睡醒 → 原路返乡、告示板领奖。任务与家园、仓储、旧村庄 ID 保留；原两座村内桥不受影响。
- 亲手修桥需建造1级、木板6、石料4，或额外10金币请工匠；修复后双向免费。另一条路线单程船票6金币。桥和船都在对应关口确认后才通行。
- 永久绳索6金币；翻山消耗当前体力60、180游戏分钟，返程消耗20、120分钟。报价展示差额、耗时、到达时刻；若完成时间达到01:00则拒绝，库存和进度不变。
- 免费营地小憩30分钟/+20体力，热食3金币/15分钟/+20体力；渡口、山脚、旅店各有游戏日一次的帮工，避免零钱不足锁住旅程。没有新增现实成长点来源或改变每日额度。
- 交信一次补贴12金币；客房8金币/游戏夜。重复订房、重复交信、并发与丢失响应重试不重复扣费或发奖。必须付款并走近床铺才能睡觉，睡醒仍在旅店；下一晚重新收费。01:00昏倒仍返家、扣生命、不恢复体力。
- 沿用原 Hearthwood 木石、苔绿与亚麻纸面，中文文字和所有操作为 DOM；新地图继续使用既有树木、建筑和家具。远行地图为路线示意，跨图追踪经真实出口选择下一关口，不触发传送。手机横屏支持滚动操作与触控替代。
- 阿渡与岚姨各有独立原创形象、头像和静态场景帧。阿渡：草帽、靛蓝衣、船桨；岚姨：银发髻、绿披肩、赭色围裙和钥匙。两人是固定服务角色，本轮没有伪称四向行走动画或日程。
