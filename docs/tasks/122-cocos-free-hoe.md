# 家园锄头自由开垦 — 2026-10-22

用户要求：家园内所有合适草地可用锄头直接开垦，只消耗体力，支持连续操作，不逐块弹窗。

- `farming.py/rules.py`在原玩家锁与幂等回执内验证坐标/ID一致、距离、地形、重复开垦和体力；每格4体力，金币/木材/石料费用为空，家园升级仍保留原作物加速收益。SQL模式不变。
- Cocos世界按钮/H装备锄头，指向框标明单格位置；点击、触屏点按、拖动扫过相邻格、按住空格随WASD移动或E单次挥锄，直接在世界结算，不打开土地确认弹窗。远处目标实际走近；最多排队16格逐一处理。Esc、菜单、失焦、缩放与触控取消停止未执行输入；已发出的请求按原回执结算，不伪造撤销。低体力/不确定连接停止后续批次。
- 收起锄头后，现有田地点击仍打开播种/浇水手记，成熟作物直接收获；恢复空田仍明确确认并消耗2体力。目录为所有新旧田地显示唯一的家园行列名称。
