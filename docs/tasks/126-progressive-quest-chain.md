# 渐进主线与支线开放（任务126）

用户目标：种植、制作、建造、养殖和战斗形成渐进主线；支线随进度开放，离村任务到适当阶段才出现。

## 实施与验收计划

1. 核对实际规则与并行养殖接口。服务端定义安家→收获交付→制作→修缮→养殖照料→首层初探→调查石门→启门准备→离村；之后的渡河与抵城另分短任务。没有出现的任务不下发到日志。
2. 收获统计与实物交付独立，交付原子扣除。前序明确提供一次性牧场筹建补助；只要求首轮照料，不等待动物成年或产蛋。支线、提前完成的行为、手动追踪与旧存档均保留。
3. 同步世界目标、任务纸页、指南和导航，避免旧远行提示抢先出现。复用现有材质与美术，桌面/横屏均可读，所有关键条件在行动前明确。
4. 后端自然动作链、错误与重复结算、旧档、客户端状态测试；真实Creator构建；隔离数据库浏览器验证阶段切换、重连、键盘和触控，并查看截图。
5. 写入实际证据、差异与剩余项，关闭本任务工具；不提交、推送、部署或操作玩家数据库。

## 当前状态

规则、界面与本机工程验收已完成。基线哈希见 `output/quest-chain-126/baseline.json`。其他聊天正在修改养殖、战斗和商店，故使用独立源码快照、Creator副本、端口及临时数据库验证，不覆盖默认预览或操作玩家库。

## 实现

主线依次为：安家 → 亲手收获并交付4份白萝卜 → 制作1块木板 → 修缮小屋到2级 → 建禽舍、买小鸡、首次喂养 → 装备武器、首层实战和工坊回顾 → 图书馆与石门调查 → Boss门钥石及魔法3级准备 → 嵌石离村。渡河、抵城交信和住宿另分短任务，回村报平安为可选支线。

- 未开放任务不进入服务端日志投影，客户端没有提前罗列锁定章节。支线按进度少量开放，手动追踪优先。
- 收获经历与当前背包数量独立；交付原子扣除4份萝卜，失败不扣，重试复用同一回执。已结算任务保留完成勾选。
- 木板任务给修缮材料；修缮回礼明确包含140金币牧场补助、20金币酬谢及木石饲料。自然收入足够建禽舍、买鸡喂养并购买基础剑；不等成年或产蛋。
- 首次战斗只要求首层；深入前明确说明门钥石、魔法3级及从0级起至少3小时的现实约定等待。没有改动现实计时或自动发放成长。
- 离村在渡口结算，渡河在对岸山路营地结算，抵城在旅店结算，避免为了领奖额外折返。已领取离村回礼仍保有交信资格。
- 已接受的旧契约保留原目标、奖励和稳定ID；旧远行档继续原旅程及旧支线，不被新教学链倒退阻拦、不补发历史奖励。
