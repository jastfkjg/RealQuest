- 本表基于实际入口、命令调用和工具链审计。任务35–38是历史验证证据，不等于本次重跑通过，也不等于玩家已接受 Cocos 的画面与手感。原始审计没有运行浏览器或功能测试；后续各构建/测试证据见任务40–45。
- 标记：**已接入**表示存在可达实现；**部分**表示已有实现但功能/入口不足；**缺少入口**表示未发现对应可达 UI；**待验证**不能按文档或代码存在直接判为完成。下面所有未勾选条件都是开放项。
