# 村庄视觉与交互改造

## 现状与方向

2026-10-09，实际运行 React 19 / Phaser 3.90 / FastAPI 项目。改造前截图：`output/visual-overhaul/before.png`（1440×900）。现有地图 1920×1280，包含四个室内、六项任务、服务端碰撞、资源与存档。保留现有业务和对象标识。

视觉方向：参考用户提供的俯视村庄构图，绿色林冠、暖色木屋、自然泥土路、蓝绿河水。世界占满视口，羊皮纸仅用于小型 HUD 和可关闭面板。中文使用系统字体。

内容结构：左上角色与资源；右上地点、设置和折叠委托；底部短快捷栏；靠近目标才出现交互提示。桌面键盘/点击，触屏方向控制。

交互方向：四向行走、轻柔镜头跟随、邻近高亮、NPC 转向与呼吸、逐字对话、采集/奖励浮字、少量水波与烟雾。减少动态效果与静音可设置。

## 实施顺序

1. 统一 16px 源素材与整数渲染，替换棋盘草地、矩形道路和同质建筑；按用途布置生活细节，维持现有碰撞与入口。
2. 全视口画布、紧凑浮动 HUD、可折叠任务，统一面板与快捷栏。
3. 邻近提示、朝向锁定、NPC idle、逐字对话、资源/经验反馈、可选音效；清理生命周期监听。
4. 构建与规则回归，浏览器检查 1440×900、1920×1080、390×844、768×1024、移动横屏；验证移动、寻路、进出、委托、成长、存档恢复。

## 地图工作流

本轮分阶段迁移：服务端地图继续作为权威碰撞/对象定义，客户端独立地图美术配置描述地形与装饰，不改变存档坐标。完整 Tiled 碰撞与对象导入后续再做，避免两套权威地图发生偏差。

## 已实施

- 独立 `village.ts` 以 16px 原图、2 倍世界像素渲染；地面一次烘焙成缓存纹理。宽屏镜头采用 1×/2×整数缩放，狭窄室内允许按视口适配以显示出口。
- 道路轮廓、草地变化与河岸重新绘制；树木、房屋、长椅、井、木桶、花丛和工作区引入合法 CC0 贴图。原有角色与门口、任务/资源/碰撞坐标不变。
- `game-ui.css` 统一全视口画布、浮动角色 HUD、羊皮纸面板与短快捷栏。触屏显示方向与互动按钮，桌面通过小型场内 E 提示与对象点击互动。
- NPC 朝向与 idle、逐字对话/直接显示、交互前面向目标、面板期间停用移动、全屏包含 HUD。
- 采集、经验与升级浮字和短粒子，水波/烟雾，原创新合成音效；静音默认，偏好保存在本机。减少动态效果同时控制镜头插值与环境效果。
- 移除原来未再使用的程序树木/房屋/地面绘制，保留资源、作物、室内家具与规则。

## 范围与后续

- 本轮不改变后端业务、数据结构或存档版本，也不重置已有存档。
- 室内家具/作物仍是原有原创绘制；未把整个美术体系声称为全新定制素材。
- 地图权威碰撞与对象仍由服务端定义，完整 Tiled 对象/碰撞工作流尚未迁移。
- NPC 当前采用轻量 idle 与转向，尚无巡逻和完整日程；AI 服务保持项目原状态，入口可用但未接入。
- 手机验证为 Chromium 的触屏模拟；真机 Safari 和低端设备性能仍需要后续验证。
