# 玩法与规则

## 基础循环

进入回响大陆 → 移动发现对象 → 采集木材/石料 → 种植萝卜 → 离线或在线等待 → 收获 → 出售/制作 → 升级家园。现实学习解锁符文探索，现实运动提高体魄；基础采集与种植不要求现实打卡。

户外地图为 1920×1280 逻辑像素（旧版面积的 4 倍），以 16px 为基础尺度，包含向阳家园、回响村庄、微光林地、旧采石场与风铃湖畔。河流有两座桥。小屋、工坊、图书馆、公会与杂货铺各有 480×368 独立室内，家具具有碰撞与实际操作。

户外镜头跟随，室内镜头居中。点击地面进行网格寻路，点击家具/对象会先靠近再互动；键盘或触控方向输入会取消自动行走。全域地图标记目的地，跨室内导航先指向出口或目标建筑。场景、位置、任务、仓储、对象冷却、农田、建筑、NPC 关系及事件持久化。

## 当前确定性数值

| 项目 | 规则 |
| --- | --- |
| 初始物资 | 20 金币、6 种子，无免费木材/石料 |
| 采集 | 每次 3 木材或石料；资源点 30 秒恢复；体魄 EXP ≥50 时 +1 |
| 体力 | 初始 100；成功采木/采石消耗 4/6，失败不扣；步行、对话、记录和整理不消耗 |
| 体力恢复 | 每 720 秒现实时间恢复 1，离线有效；上限处不囤积时间；床边睡觉补满，不推进作物或日期 |
| 现实委托 | 诺亚对话领取学习／运动／工作，1–5 小时；每小时 1 知识／健康／技能点；三类每日合计 5 点，同时一项 |
| 体力培养 | 主动投入 1 健康点，体力上限和当前体力各 +5；生命培养与技能分配后续实现 |
| 计时与结算 | 服务端记录领取时间与到期时间；到期后回诺亚身边结算一次。取消释放预留额度、无部分奖励；跨天归领取日（中国标准时间） |
| 科学／魔法 | 从 0 开始，主动投入 1 知识点使所选方向 +1 级；当前没有额外道具或法术效果 |
| 种植 | 消耗 1 种子，60 秒成熟，收获 2 萝卜 +1 种子，无枯萎 |
| 小屋升级 | 2 级起新种作物改为 45 秒成熟 |
| 出售萝卜 | 单份收入 `8 + 工坊等级 - 1` 金币 |
| 买种子 / 制作 | 2 金币买 1 种子；3 木材制 1 木板 |
| 建筑升级 | 上限 3 级；消耗 `当前等级 × (6 木材 +3 石料 +10 金币)` |
| 图书馆 | 首次符文事件获得 `3 × 图书馆等级` 知识碎片 |
| 总等级 | `1 + floor(总 EXP / 100)` |
| 属性等级 | `1 + floor(该属性 EXP / 50)` |
| 步数 | 同日累计步数增量，每 500 步 2 体魄 EXP，计奖步数最多 10000 |
| 学习 / 运动 / 创造 | 每完整分钟 1 对应属性 EXP，单次至多计 120 分钟 |
| 生活管理 | 每天一次 10 经营 EXP，不读取消费金额 |
| 每日上限 | 每个属性从现实活动获得最多 100 EXP；补记按行为日期计算 |
| 探索能量 | 每次步数/运动所获 EXP 的一半，向下取整；暂无消耗入口 |
| 知识碎片 | 每日每累计 25 学识活动 EXP 获得 1 个；暂无消耗入口 |
| NPC | 每名 NPC 每自然日首次对话 +1 关系、+5 联结 EXP |
| 符文 | 学识 EXP ≥25 且邻近遗迹可触发一次，获得 15 学识 EXP 与碎片 |

现实属性不衡量玩家真实健康、智力或价值。没有消费金额转金币、充值、提现或现金兑换机制。

## 内容边界

目前有八个固定剧情委托，支持接取、追踪、目标完成、交付和一次性奖励；不等于自定义现实目标或每日任务。首个安家任务自动接取，后续到告示板或 NPC 接取；接取与交付均校验场景和距离。采集、收获、出售、制作使用累计计数，花掉材料不会倒退进度。NPC 对话是根据当前条件选择的预设文本。木板可在杂货铺出售；探索能量、知识碎片尚缺消费与更深层玩法。当前节奏用于短时体验，正式数值、长期目标、AI 任务、更多技能与职业均见 TODO。

## 杂货铺与村民订单

米拉在风铃杂货铺常驻。买种子每份2金币；收购木材2、石料3、木板8金币，萝卜沿用工坊等级报价。数量可选1／5／10份，服务端限制1–99整数，校验库存与距离。工坊旧交易保持可用。出售物品和交付订单都是纯游戏内金币来源，与现实委托点数分开。

每天北京时间三份订单：6木材→18金币、4石料→20金币、4萝卜→44金币。交付一次扣材料并发回报；订单未完成没有损失，零点刷新。服务端核对日期，过期界面不能误交。新统计仅记录功能上线后的交易和订单收入，不从旧余额猜测收入。存档版本3只为新增字段与杂货铺占地内的旧位置做兼容；其他记录和余额不变。

## 健康与体力切片（2026-10-14）

后续知识成长已在本轮继续实现，见下方知识研修规则；此节保留健康切片自身的边界。

新成长点数统一来自诺亚的现实委托。领取时预留当日额度，已结算额度不会因花掉知识点或健康点而恢复。取消后重新领取从新的服务器时间开始，不继承已等待时长。达到每日 5 点后拒绝新委托，次日零点恢复新日额度；仍有进行中委托时需先结算或取消。关闭页面、离线都计入等待，但计时不验证真实行为。

健康点仍可主动投入，每点使当前体力和上限各 +5；知识点可主动投入科学／魔法，每点 +1 级。技能点用于种植／养殖／建造等级：从 0 级开始，升级至 N 级消耗 N 点。角色档案用三类闲置点主动升级，不显示 EXP 进度；生命值初始 100/100，每次消耗 1 健康点使当前值和上限各 +5。生活技能与科学／魔法等级独立保存，具体技能收益、养殖玩法与战斗仍未开放。旧经验、碎片、点数和成长等级保留；旧学习任务或锻炼约定的计时、关联、修改目标不再发成长点数，不能绕过委托上限。原有活动 EXP 与解锁规则保留，不混同新的每日点数额度。
