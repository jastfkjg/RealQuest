# 玩法与规则

更新：2026-10-16。本文前半部分记录当前规则；后半部分记录第一章与长期成长设计，其中日夜与家中睡眠已交付候选，其余按范围标注。具体开发顺序见 [TODO.md](../TODO.md)，视觉与交互约束见 [DESIGN.md](../DESIGN.md)。设计确认不等于实机或美术验收。

## 当前基础循环

进入回响大陆 → 移动发现对象 → 采集木材/石料 → 种植萝卜 → 离线或在线等待 → 收获 → 出售/制作 → 升级家园。现实学习解锁符文探索，现实运动提高体魄；基础采集与种植不要求现实打卡。

户外地图为 1920×1280 逻辑像素（旧版面积的 4 倍），以 16px 为基础尺度，包含向阳家园、回响村庄、微光林地、旧采石场与风铃湖畔。河流有两座桥。小屋、工坊、图书馆、公会与杂货铺各有 480×368 独立室内，家具具有碰撞与实际操作。

户外镜头跟随，室内镜头居中。点击地面进行网格寻路，点击家具/对象会先靠近再互动；键盘或触控方向输入会取消自动行走。全域地图标记目的地，跨室内导航先指向出口或目标建筑。场景、位置、任务、仓储、对象冷却、农田、建筑、NPC 关系及事件持久化。

| 现实委托 | 诺亚对话领取学习／运动／工作，1–5 小时；每小时 1 知识／健康／技能点；三类每日合计 5 点，同时一项 |
| 体力／生命培养 | 主动投入 1 健康点，使所选体力或生命的上限和当前值各 +5；生命初始 100/100 |
| 计时与结算 | 服务端记录领取时间与到期时间；到期后回诺亚身边结算一次。取消释放预留额度、无部分奖励；跨天归领取日（中国标准时间） |
| 科学／魔法 | 从 0 开始，主动投入 1 知识点使所选方向 +1 级；当前没有额外道具或法术效果 |
| 种植 | 消耗 1 种子，60 秒成熟，收获 2 萝卜 +1 种子，无枯萎 |
| 小屋升级 | 2 级起新种作物改为 45 秒成熟 |
| 出售萝卜 | 单份收入 `8 + 工坊等级 - 1` 金币 |
| 买种子 / 制作 | 2 金币买 1 种子；3 木材制 1 木板 |
| 建筑升级 | 上限 3 级；消耗 `当前等级 × (6 木材 +3 石料 +10 金币)` |
| 图书馆 | 首次符文事件获得 `3 × 图书馆等级` 知识碎片 |
| 总等级 | `1 + floor(总 EXP / 100)` |
| 属性等级 | `1 + floor(该属性 EXP / 50)` |
| 步数 | 同日累计步数增量，每 500 步 2 体魄 EXP，计奖步数最多 10000 |
| 学习 / 运动 / 创造 | 每完整分钟 1 对应属性 EXP，单次至多计 120 分钟 |
| 生活管理 | 每天一次 10 经营 EXP，不读取消费金额 |
| 每日上限 | 每个属性从现实活动获得最多 100 EXP；补记按行为日期计算 |
| 探索能量 | 每次步数/运动所获 EXP 的一半，向下取整；暂无消耗入口 |
| 知识碎片 | 每日每累计 25 学识活动 EXP 获得 1 个；暂无消耗入口 |
| NPC | 每名 NPC 每自然日首次对话 +1 关系、+5 联结 EXP |
| 符文 | 学识 EXP ≥25 且邻近遗迹可触发一次，获得 15 学识 EXP 与碎片 |

现实属性不衡量玩家真实健康、智力或价值。没有消费金额转金币、充值、提现或现金兑换机制。

## 内容边界

目前有八个固定剧情委托，支持接取、追踪、目标完成、交付和一次性奖励；不等于自定义现实目标或每日任务。首个安家任务自动接取，后续到告示板或 NPC 接取；接取与交付均校验场景和距离。采集、收获、出售、制作使用累计计数，花掉材料不会倒退进度。NPC 对话是根据当前条件选择的预设文本。木板可在杂货铺出售；探索能量、知识碎片尚缺消费与更深层玩法。当前节奏用于短时体验，正式数值、长期目标、AI 任务、更多技能与职业均见 TODO。

## 杂货铺与村民订单

米拉在风铃杂货铺常驻。买种子每份2金币；收购木材2、石料3、木板8金币，萝卜沿用工坊等级报价。数量可选1／5／10份，服务端限制1–99整数，校验库存与距离。工坊旧交易保持可用。出售物品和交付订单都是纯游戏内金币来源，与现实委托点数分开。

每天北京时间三份订单：6木材→18金币、4石料→20金币、4萝卜→44金币。交付一次扣材料并发回报；订单未完成没有损失，零点刷新。服务端核对日期，过期界面不能误交。新统计仅记录功能上线后的交易和订单收入，不从旧余额猜测收入。存档版本3只为新增字段与杂货铺占地内的旧位置做兼容；其他记录和余额不变。

## 健康与体力切片（2026-10-14）

本节记录健康与体力切片之后的现行成长规则；早期切片报告中的点数来源已由 NPC 现实委托规则替代。

新成长点数统一来自诺亚的现实委托。领取时预留当日额度，已结算额度不会因花掉知识点或健康点而恢复。取消后重新领取从新的服务器时间开始，不继承已等待时长。达到每日 5 点后拒绝新委托，次日零点恢复新日额度；仍有进行中委托时需先结算或取消。关闭页面、离线都计入等待，但计时不验证真实行为。

健康点仍可主动投入，每点使当前体力和上限各 +5；知识点可主动投入科学／魔法，每点 +1 级。技能点用于种植／养殖／建造等级：从 0 级开始，升级至 N 级消耗 N 点。角色档案用三类闲置点主动升级，不显示 EXP 进度；生命值初始 100/100，每次消耗 1 健康点使当前值和上限各 +5。生活技能与科学／魔法等级独立保存，具体技能收益、养殖玩法与战斗仍未开放。旧经验、碎片、点数和成长等级保留；旧学习任务或锻炼约定的计时、关联、修改目标不再发成长点数，不能绕过委托上限。原有活动 EXP 与解锁规则保留，不混同新的每日点数额度。

## 村民生活切片（2026-10-16，已实现候选）

莉亚、诺亚、米拉使用三个独立的原创人物与头像，不经过玩家外观注册表。每人按游戏时间工作、外出、相聚、歇脚，沿可通行路线走到建筑门口后进出；邻里簿与地图显示实际位置，导航仍为步行指引。

作息与睡眠共用 `world_clock`，不建立另一套村民时间。村民切片最初采用08:30起点与10秒离线余量，现由下方日夜规则替代：新旅程06:00开始，断联租期到期后丢弃未确认尾段，保留已提交的旧旅程时刻。旧视图的暂停不能覆盖新的活跃视图；作物／资源仍按现实时间运行。

首次问候沿用每人每日熟悉度+1、联结EXP+5。送出背包中1份实物，最爱物品熟悉度+2，其余+1；帮忙消耗4体力并增加熟悉度1。每人每天各限一次送礼／帮忙，日期沿用北京时间，跳转村庄日不会刷新额度。熟悉度5解锁个人故事；无额外金币或成长点。莉亚最爱木板，诺亚和米拉最爱萝卜。所有话题为预设村庄内容，帮忙是游戏内互动。

米拉外出时，杂货铺寄售柜台仍可买卖和交付每日订单，剧情委托需找到本人。诺亚可以在实际所在地点办理现实委托，其领取、到期、额度与结算仍按真实服务端时间。详见[实现与验证记录](tasks/25-village-residents.md)。

## 日夜与睡眠切片（2026-10-16，已实现候选）

- 24 小时显示；游戏日从06:00延续至次日01:00，午夜仅显示00:xx，不提前切换游戏日编号。新旅程06:00开始，沿用原村民时钟速度，不在本轮另调经济数值。
- 到床边按E或触控打开休息选择，阅读时暂停。免费睡眠进入次日06:00，体力补满、生命恢复最多20；免费小憩推进30游戏分钟、恢复最多20体力和10生命，不允许短休跨过01:00。
- 确认的活跃世界时间到01:00时昏倒，次日06:00回到家中可通行的床边，扣最多10当前生命且最低1，剩余体力保留。仅重置体力自然恢复的现实时间锚点，不发睡眠恢复，不扣永久成长。
- 阅读面板、现实成长、后台、离线及离页暂停游戏时间。世界视图每3秒续期，超过10秒未确认的尾段丢弃；恢复时不补算离线昏倒。新视图接管不结算旧视图未确认尾段，旧视图不能暂停新视图。
- 睡眠使用结束日作为业务校验，叠加现有请求回执和服务端事务；丢失响应、不同请求重复点击、跨日竞争只结算一夜。昨日延迟的移动或采集不会覆盖返家状态。
- 旧存档只增补时钟版本；旧村民时钟保留已提交的可玩时刻，旧01:00–06:00安全调整到06:00，不追罚。库存、仓储、容量、任务、已种作物、资源冷却和现实委托到期保留；旧存档初始化与游戏操作使用同一事务锁。
- 当前作物／资源时间戳、每720现实秒自然恢复、现实委托及每日额度仍按现实时间运行。游戏睡眠不缩短这些计时、不把跳过的游戏小时换算成现实恢复，也不刷新现实奖励。生产时钟迁移保留后续任务。

实机与测试证据见[任务26](tasks/26-day-night-sleep.md)。旅馆、离村、战斗和家园装修尚未实现；此次功能与画面仍待玩家试玩和实机视觉确认。

## 第一章与长期成长设计（2026-10-16，日夜已实现，其余待后续切片）

### 世界定位与长期循环

初始村庄是回响大陆中的偏远聚落，现有村庄及周边区域构成起始地区，不代表整片大陆。大陆上还有其他城市和地区，随剧情逐步开放。村庄中的小屋始终是玩家可以返回的长期家园。

长期循环：在村庄生活与准备 → 渡河、翻山并探索城市 → 获得图纸、法术、材料与故事进展 → 回家制作、扩建和装修 → 准备下一次远行。现实成长可以改善能力与准备效率，基础生活和第一章通关必须保留不依赖现实委托的方案。

保留 Hearthwood 的温暖林地与生活气息。科技和魔法先通过工坊、图书馆、遗迹及少量工具融入世界，再随地区发展；不因后期存在机甲而提前把村庄整体改成工业城市。参考生活模拟游戏的日程规划和家园归属感，不复制商业游戏的地图、角色、剧情或美术。

### 第一章主线：走出山谷

章节目标是第一次离开起始地区，跨过河流与山脉，进入第一座城市。叙事工作稿为“旧商路中断，玩家受托恢复通路，并带着村庄的信件前往城市”；任务名、信件内容与接头人留待任务切片确定。

开局即可通过远山、路牌、断桥和村民谈话得知城市的存在。先让玩家认识目标，再逐步获得抵达的能力；地图不能把未开放地区表现为已可抵达。

| 阶段 | 玩家行为 | 推进结果 |
| --- | --- | --- |
| 在村里落脚 | 安家、采集、制作、认识村民 | 理解家园、资源、体力和基础交易 |
| 调查离村路线 | 找到外围断桥、码头和山口 | 了解两种渡河方案与翻山准备 |
| 解决渡河 | 修桥，或取得船只通行 | 可以抵达山脚；任一方案即可推进 |
| 准备翻山 | 准备补给、绳索和体力，选择出发时间 | 完成有准备的首次远行 |
| 抵达城市 | 送信、找到旅馆、认识工坊与当地组织 | 第一章完成，开启城市任务 |

现有安家、制作木板、森林探索等任务作为铺垫，保留已完成记录与奖励。新断桥属于村庄外围的出境路线，不封锁现有两座桥及已开放地点。跨区经过实际出口和通行条件校验；地图选点仍然只选择或标记方向，不触发传送。

### 渡河：建造与乘船两条路径

| 方案 | 条件与投入 | 长期价值 |
| --- | --- | --- |
| 自行修桥 | 明确的材料清单、图纸或修复知识、建造等级 | 一次投入后永久开放，免费往返，桥体有可见变化 |
| 村民协助修桥 | 完成游戏内委托并提供所需材料，由有能力的村民施工 | 不要求玩家先提高建造等级，仍完成同一桥梁修复 |
| 乘船 | 支付船费、帮助船夫或修复旧船取得通行资格 | 较少初期建造投入，可保留班次或单次费用 |

渡河只要求一种有效方案。坐船后仍可回来修桥，不因选择路线失去主线奖励。具体材料、费用、建造等级、班次和帮助船夫的任务内容尚未定值；第一章首版先保证桥与船各有一条完整可玩的路径，再扩充分支。

建造门槛约束自主施工，不成为全体玩家的唯一出口。村民协助不额外创造现实成长点数，也不改变现有点数来源。材料交付、施工完成和船费扣除须由服务端确认，失败或重试不能重复扣料、扣费或发奖。

### 翻山：体力、装备与行程

- 当前体力决定能否开始或继续攀登；体力上限影响补给压力和可选路线，两者分别显示。
- 普通山路配合绳索与合理补给，应允许初始体力上限为 100 的角色完成。更高体力可减少准备或开放捷径，不强制等待现实运动委托结算。
- 出发前显示所需物品、预计体力消耗、预计抵达时间与已知风险。准备不足时提供明确缺口、补给地点或返回选择，不在途中突然出现未告知的硬性等级锁。
- 山路具有可识别的途中地标与安全折返点；基础步行与对话仍可使用。首版不要求先完成战斗才能抵达城市。
- 首次翻山保留旅程感，之后逐步修复便道、稳定渡船，再考虑驿车。驿车等便捷旅行属于后续独立切片，必须显示时间、费用和目的地，不是地图上的隐式传送。

### 游戏日夜与两种时间

游戏世界采用 24 小时制。通常于 06:00 起床，次日凌晨 01:00 为强制睡眠截止时间；睡眠期间跳转到次日早晨。第一切片沿用原村民时钟的30现实分钟／24游戏小时，19个游戏小时为23分45秒活跃时间；最初25–30分钟的设想仍作为后续试玩调速参考。

| 时间域 | 管理内容 | 暂停与跨日规则 |
| --- | --- | --- |
| 游戏时间 | 已有 NPC 作息与村庄明暗；后续旅程、睡眠、旅馆住宿和生产节奏 | 有效世界游玩时推进；睡眠进入下一游戏日 |
| 现实时间 | 现实委托到期、专注计时、现实活动日期和成长额度 | 沿用服务端计时与 Asia/Shanghai 日期；不被游戏睡眠、暂停或旅行推进 |

离线、页面进入后台、断线而无法确认世界推进、切换 Life Mode 时暂停游戏世界，恢复后不补算离线期间的昏倒。现实委托继续到期，专注计时沿用现有显式暂停规则。暂停不提供移动、采集、制作或攻击机会；时间和状态由服务端维护，不能信任客户端自报经过时长。

非战斗背包、剧情对话等需要阅读的上下文暂停整个世界。未来战斗中的菜单必须统一暂停世界、敌人和冷却，不能只暂停日夜而让某一方继续行动。刷新和多标签页不能重置一天或造成重复推进。

游戏睡眠不会刷新现实委托的每日 5 点额度、现实活动奖励上限，也不会缩短现实委托或专注时长。当前村民订单与首次对话奖励仍按现实日结算；以后迁到游戏日时须明确规则和兼容方案，不能顺带扩大现实成长奖励。

### 睡眠、旅馆与昏倒

- 家中床铺免费；旅馆以游戏金币预订并提供可使用的床位。付款前显示费用和适用住宿夜，付款后进出房间不重复收费，支付失败不授予住宿。
- 正常上床结束当天，次日早晨补满体力；首个切片恢复最多20生命，免费短休提供日间补充。食物补给属于后续玩法。
- 夜间分阶段提醒临近 01:00，并提供家或有效旅馆床位的方向。提醒不替代玩家的睡眠操作，路线和住宿状态须如实显示。
- 到 01:00 仍未睡觉则昏倒，下一游戏日早晨回到自己家中，扣除一定当前生命值，不获得当晚睡眠的体力恢复。“不恢复”不等于额外把剩余体力清零。
- 昏倒不降低生命或体力上限，不扣健康点、知识点、技能点及现实成长；该生命扣减不致死。连续昏倒不叠加永久惩罚，也不对离线或错过现实日期处罚。
- 零体力仍可步行、对话和整理，需有可达、低成本的食物或短休恢复途径。抵达城市时提供清楚的旅馆价格和可完成的住宿收入任务，避免身无分文后进入无法恢复的循环。
- 住宿预订扣费独立完成一次权威结算；跨夜时将日期、恢复或昏倒扣血及返家位置一并保存，不再次扣房费。睡眠与截止时间发生竞争、网络重试、刷新或多标签页时，各业务结果只结算一次。

界面统一使用“生命值”表示角色 HP，“体力”表示行动储备，“健康点”表示现实委托成长资源；游戏中昏倒不代表玩家现实健康状况。

### 现有时间规则的过渡

第一切片已把床边立即恢复替换为次日睡眠与短休；每720现实秒自然恢复、作物60秒成熟（小屋2级后新作物45秒）和资源30秒恢复继续有效，相关界面明确说明。睡眠跳过的游戏时间不推进这些现实时间戳。

日夜切片必须一起定义睡眠推进、自然恢复与作物／资源时钟的关系。目标是让世界内生产逐步使用游戏时间、现实成长继续使用现实时间；不把“游戏睡一夜”误算为现实恢复时长，也不让新旧恢复重复发放。迁移须保留已种作物的剩余成熟进度、资源冷却、当前资源、容量、现有建筑效果和委托到期时间，不清空玩家数据。首版恢复途径必须与昏倒规则一起交付；生产时钟迁移若另行交付，应明确标注仍按现实时间运行的内容。

### 科技与魔法：第二章开始分化

现有科学／魔法等级继续使用原字段与知识点规则，设计中的“科技路线”对应现有“科学”等级。能力须获得实际图纸、装备或法术并完成学习／制造后才能使用；等级存在不等于已经拥有能力。

| 方向 | 核心体验 | 发展路径示例 | 非战斗用途 |
| --- | --- | --- | --- |
| 科技 | 预先制造、装备配置与补给管理 | 简易工具 → 手枪 → 自动装置／机械伙伴 → 个人驾驶机甲 | 照明、灌溉、采矿、运输 |
| 魔法 | 学习施法、时机判断与效果组合 | 点火／照明 → 火球 → 冰霜／护盾 → 更高阶法术 | 点燃炉火、洞穴照明、发现隐藏物、解除封印 |

科学等级主要约束图纸理解、制造与升级，是否有特殊装备操作要求按物品说明；魔法等级主要约束学习，具体施法还受已学法术、消耗与冷却约束。初期允许主修一种并兼学另一种，不锁死职业，关键主线不要求两边同时升高。

两条路线都要能完成基础战斗与探索任务，分别提供合理解决方式。首个战斗切片只做一件科技武器、一个可用法术、少量敌人和补给闭环；弹药、施法消耗、命中方式与死亡恢复届时定稿，不预先堆叠多个未使用资源条。个人驾驶机甲及复杂自动战斗放在中后期，不纳入第一章。

### 第一座城市与首个战斗任务

先交付紧凑城市入口区：旅馆、工坊、任务接头人，以及认识科技与魔法的入口。抵达、送信、找到住处构成完整第一章终点，无需先完成清怪任务。

第二章的首个任务工作稿为“调查旧水站 → 处理盘踞怪物 → 恢复供水”。任务提供可用的基础科技或魔法方案，完成后让设施或 NPC 状态发生可见变化。任务地点、敌人、奖励和正式名称尚未确定；不在仅有任务钩子时显示为可执行或已完成。

### 家园扩建与装修

家园承接远行成果：城市图纸、材料和家具可以带回村庄，增加功能和个人表达，再支持下一次出发。

| 层次 | 内容 | 交付顺序 |
| --- | --- | --- |
| 功能升级 | 储物扩容、厨房、制作台、阅读区 | 先为已有房屋升级增加实际功能与可见阶段变化 |
| 空间扩建 | 新房间、工坊附屋、庭院区域 | 功能升级稳定后分区扩建 |
| 自由装修 | 家具移动／旋转、地毯、灯具、墙地面样式 | 先少量可摆放家具，再扩展自由装修 |

普通装饰以表达为主，功能设施提供明确收益，不强迫玩家靠堆家具提升战斗数值。家具和扩建有获取来源、材料或金币消耗；确认前显示费用和效果，不能用未制作的示意图声称房屋已升级。

保留既有建筑等级、制作收益、储物内容和房屋身份。布局持久化，家具不能堵死床、门、必要工作台或角色落点；提供移动、收回和取消预览。扩建后角色与仓储仍可恢复。新的外观和布局需要独立实机检查，不把本次文字确认视为画面验收。
