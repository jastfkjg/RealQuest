# 玩法与规则

## 基础循环

进入回响大陆 → 移动发现对象 → 采集木材/石料 → 种植萝卜 → 离线或在线等待 → 收获 → 出售/制作 → 升级家园。现实学习解锁符文探索，现实运动提高体魄；基础采集与种植不要求现实打卡。

户外地图为 1920×1280 逻辑像素（旧版面积的 4 倍），以 16px 为基础尺度，包含向阳家园、回响村庄、微光林地、旧采石场与风铃湖畔。河流有两座桥。小屋、工坊、图书馆与公会各有 480×368 独立室内，家具具有碰撞与实际操作。

户外镜头跟随，室内镜头居中。点击地面进行网格寻路，点击家具/对象会先靠近再互动；键盘或触控方向输入会取消自动行走。全域地图标记目的地，跨室内导航先指向出口或目标建筑。场景、位置、任务、仓储、对象冷却、农田、建筑、NPC 关系及事件持久化。

## 当前确定性数值

| 项目 | 规则 |
| --- | --- |
| 初始物资 | 20 金币、6 种子，无免费木材/石料 |
| 采集 | 每次 3 木材或石料；资源点 30 秒恢复；体魄 EXP ≥50 时 +1 |
| 体力 | 初始 100；成功采木/采石消耗 4/6，失败不扣；步行、对话、记录和整理不消耗 |
| 体力恢复 | 每 720 秒现实时间恢复 1，离线有效；上限处不囤积时间；床边睡觉补满，不推进作物或日期 |
| 锻炼约定 | 每个中国标准时间自然日一项，目标 1–120 分钟；分次手动记录或关联同日已有运动，完成一次获 1 健康点 |
| 体力培养 | 主动投入 1 健康点，体力上限和当前体力各 +5；生命培养、知识与技能分配后续实现 |
| 种植 | 消耗 1 种子，60 秒成熟，收获 2 萝卜 +1 种子，无枯萎 |
| 小屋升级 | 2 级起新种作物改为 45 秒成熟 |
| 出售萝卜 | 单份收入 `8 + 工坊等级 - 1` 金币 |
| 买种子 / 制作 | 2 金币买 1 种子；3 木材制 1 木板 |
| 建筑升级 | 上限 3 级；消耗 `当前等级 × (6 木材 +3 石料 +10 金币)` |
| 图书馆 | 首次符文事件获得 `3 × 图书馆等级` 知识碎片 |
| 总等级 | `1 + floor(总 EXP / 100)` |
| 属性等级 | `1 + floor(该属性 EXP / 50)` |
| 步数 | 同日累计步数增量，每 500 步 2 体魄 EXP，计奖步数最多 10000 |
| 学习 / 运动 / 创造 | 每完整分钟 1 对应属性 EXP，单次至多计 120 分钟 |
| 生活管理 | 每天一次 10 经营 EXP，不读取消费金额 |
| 每日上限 | 每个属性从现实活动获得最多 100 EXP；补记按行为日期计算 |
| 探索能量 | 每次步数/运动所获 EXP 的一半，向下取整；暂无消耗入口 |
| 知识碎片 | 每日每累计 25 学识活动 EXP 获得 1 个；暂无消耗入口 |
| NPC | 每名 NPC 每自然日首次对话 +1 关系、+5 联结 EXP |
| 符文 | 学识 EXP ≥25 且邻近遗迹可触发一次，获得 15 学识 EXP 与碎片 |

现实属性不衡量玩家真实健康、智力或价值。没有消费金额转金币、充值、提现或现金兑换机制。

## 内容边界

目前有六个固定剧情委托，支持接取、追踪、目标完成、交付和一次性奖励；不等于自定义现实目标或每日任务。首个安家任务自动接取，后续到告示板或 NPC 接取；接取与交付均校验场景和距离。采集、收获、出售、制作使用累计计数，花掉材料不会倒退进度。NPC 对话是根据当前条件选择的预设文本。木板、探索能量、知识碎片尚缺消费与更深层玩法。当前节奏用于短时体验，正式数值、长期目标、AI 任务、更多技能与职业均见 TODO。

## 健康与体力切片（2026-10-14）

锻炼约定独立于剧情委托和研习任务。固定每日身份让拆分提交、重复关联、重试都不能多发健康点；现有活动经验仍按原规则结算，达到经验上限不会妨碍约定完成。运动记录仍标记 manual / verified=false。每天一项约定不支持完成后重新创建或改目标刷奖励；过去约定保留，新增补记受现有七天期限约束，已有同日记录仍可关联。

现有五属性、解锁、资源与历史保持原值；旧存档默认获得满额 100 体力及零健康点，不按历史 XP 兑换。健康点是可分配奖励，体力上限是永久能力，当前体力是可恢复消耗量。以后再统一成长体系，本切片没有生命、战斗、食物、知识或技能加点。具体测试与实际画面见 [任务 11](tasks/11-health-stamina.md)。
