## 当前基础循环

进入回响大陆 → 移动发现对象 → 采集木材/石料 → 种植萝卜 → 离线或在线等待 → 收获 → 出售/制作 → 升级家园。现实学习解锁符文探索，现实运动提高体魄；基础采集与种植不要求现实打卡。

户外地图为 1920×1280 逻辑像素（旧版面积的 4 倍），以 16px 为基础尺度，包含向阳家园、回响村庄、微光林地、旧采石场与风铃湖畔。河流有两座桥。小屋、工坊、图书馆、公会与杂货铺各有 480×368 独立室内，家具具有碰撞与实际操作。

户外镜头跟随，室内镜头居中。点击地面进行网格寻路，点击家具/对象会先靠近再互动；键盘或触控方向输入会取消自动行走。全域地图标记目的地，跨室内导航先指向出口或目标建筑。场景、位置、任务、仓储、对象冷却、农田、建筑、NPC 关系及事件持久化。

## 内容边界

目前有八个固定剧情委托，支持接取、追踪、目标完成、交付和一次性奖励；不等于自定义现实目标或每日任务。首个安家任务自动接取，后续到告示板或 NPC 接取；接取与交付均校验场景和距离。采集、收获、出售、制作使用累计计数，花掉材料不会倒退进度。NPC 对话是根据当前条件选择的预设文本。木板可在杂货铺出售；探索能量、知识碎片尚缺消费与更深层玩法。当前节奏用于短时体验，正式数值、长期目标、AI 任务、更多技能与职业均见 TODO。

## 第一章与长期成长设计（2026-10-16，日夜已实现候选，其余按切片实施与验收）

### 世界定位与长期循环

初始村庄是回响大陆中的偏远聚落，现有村庄及周边区域构成起始地区，不代表整片大陆。大陆上还有其他城市和地区，随剧情逐步开放。村庄中的小屋始终是玩家可以返回的长期家园。

长期循环：在安全村庄生活、积累金币与成长点数 → 购买或打造武器、准备体能与补给 → 进入洞穴战斗并获得制作材料 → 取得魔法石、达到启门魔法等级并开启离村石门 → 渡河、翻山并探索城市 → 获得进阶图纸、法术、材料与故事进展 → 回家制作、扩建和装修 → 准备下一次远行。基础生活、手动现实记录与初次洞穴体验保持可用；首次离村则明确需要知识成长与战斗成果，不再沿用“科学／魔法0级且无现实成长也可直接离村”的规划。

保留 Hearthwood 的温暖林地与生活气息。科技和魔法先通过工坊、图书馆、遗迹及少量工具融入世界，再随地区发展；不因后期存在机甲而提前把村庄整体改成工业城市。参考生活模拟游戏的日程规划和家园归属感，不复制商业游戏的地图、角色、剧情或美术。

### 第一章主线：走出山谷

章节目标是完成村庄阶段的准备与成长，开启被大石门封住的外出通道，再跨过河流与山脉进入第一座城市。叙事工作稿为“村外旧通道被石门封闭，玩家调查洞穴取得魔法石，学会启门后带着村庄的信件前往城市”；新增任务名称、洞穴背景与石门来历留待切片确定。已有送信任务名称与接头人以任务27的实现记录为准。

开局即可通过远山、路牌、断桥和村民谈话得知城市的存在。先让玩家认识目标，再逐步获得抵达的能力；地图不能把未开放地区表现为已可抵达。

| 阶段 | 玩家行为 | 推进结果 |
| --- | --- | --- |
| 在村里落脚 | 安家、采集、制作、认识村民 | 理解家园、资源、体力和基础交易 |
| 调查离村路线 | 发现封路石门、洞穴入口及通往城市的线索 | 提前了解魔法石、启门等级与后续旅途需求 |
| 村庄准备与成长 | 经营赚取金币，培养技能、知识和体能，购买或满足配方等级后打造武器 | 获得可用装备、补给及洞穴探索准备 |
| 洞穴探索与战斗 | 主动进入战斗地点，逐层探索、收集材料并挑战底层Boss | 取得关键魔法石与可用于制作的普通材料 |
| 开启离村石门 | 持有指定魔法石，达到启门魔法等级，在石门前确认开启 | 永久打通通往渡口的共同出口 |
| 解决渡河 | 修桥，或取得船只通行 | 可以抵达山脚；任一方案即可推进 |
| 准备翻山 | 准备补给、绳索和体力，选择出发时间 | 完成有准备的首次远行 |
| 抵达城市 | 送信、找到旅馆、认识工坊与当地组织 | 第一章完成，开启城市任务 |

现有安家、制作木板、森林探索等任务作为铺垫，保留已完成记录与奖励。新断桥属于村庄外围的出境路线，不封锁现有两座桥及已开放地点。跨区经过实际出口和通行条件校验；地图选点仍然只选择或标记方向，不触发传送。

### 定点战斗：主动进入洞穴探索

怪物只出现在有明确入口与边界的战斗地点，例如进入后的山洞、遗迹内部或专门开放的地下区域。村庄、普通林地道路、渡口、山路与城市街道不随机刷怪；怪物不追出战斗地点进入安全区域。城市进阶任务也须遵循这一边界。

第一切片只做一处村庄附近的5层洞穴，1–4层共15只普通怪，5层为生命160／物理护甲2的石壳守卫Boss；均为v1候选参数，不展开完整矿洞、随机地牢或多洞穴系统。3层打通后开放洞内绳梯与安全平台，普通怪下一游戏日重置、通路永久保留，Boss撤退后重置。洞穴入口、已知危险、进入／退出与撤退操作应清楚可见；详细配置、失败与保存规则以数值文档为准。

主线工作稿为“调查石门 → 购买或打造武器并准备补给 → 进入洞穴逐层战斗 → 击败底层Boss取得魔法石 → 达到启门魔法等级 → 回到石门开启通道”。成长与探索可交错进行；石门要求在首次调查时就完整展示，避免打完Boss后才告知还需提升魔法等级。旧护路委托不再作为独立离村判定。

初次进入洞穴先教攻击、识别攻击预兆与退让，允许用买来的基础武器开始积累战斗经验。工坊与图书馆提供简单科技工具、入门法术、研修与制作入口；能力的预览、已学、已制造与实际持有须准确区分。首件武器的购买或入门配方不能只依赖尚未打过的怪物掉落，避免先有武器才能刷材料、先刷材料才能有武器的循环。

战败提供可达、低成本的恢复和重试途径，不损失永久成长点数。低体力时仍可在安全地点恢复、整理或撤退；Boss与深入探索可以要求更充分的生命／体力、装备和补给准备。命中、攻击消耗、冷却与恢复数值在实现前定稿，沿用现有生命／体力。阅读、菜单、Life Mode 和后台暂停须同时冻结整个战斗世界、敌人、伤害与冷却。

### 武器：购买、打造与数值差异

武器既可用游戏金币购买，也可取得图纸后自行打造。v1候选为石刃短剑24金币、加固短剑96金币、弹簧长矛与微光短杖各120金币；详细伤害、攻击间隔、距离、体力与配方集中在数值文档。物品详情与商店对比使用同一份规则，不用“更强”文案替代数值，不在本切片提前扩展随机词条、耐久或复杂装备树。

打造需要图纸、材料、建造等级，以及配方指定的科学或魔法等级。v1均要求建造1级；通用短剑需科学1或魔法1，弹簧长矛需科学1，微光短杖需魔法2。每张配方明确门槛，不能只满足知识等级就跳过建造要求。参数作为候选待试玩，等级不足不扣材料，失败与重试不重复扣料或产出。

购买武器以金币与实际商品为条件，不沿用自制时的制造等级门槛；如武器另有使用要求须事先说明，至少一件可购买的基础武器允许新角色装备。玩家可用经营收入替代部分自制投入，也可投入建造与知识成长改善自制选择；自行打造所有武器不作为额外出村条件。

### 战斗掉落与首次制作

战斗掉落提供可辨认的制作材料，与村庄既有木材、石料等资源共同形成“战斗 → 获得材料 → 制作物品 → 再探索”的循环。科技侧偏向预先制造、装置配置与补给，魔法侧包含已学法术与可制造的法器／护符；同一种材料可服务两条路线，成品须有实际使用差异。

下表仅为设计示例，不代表已安装素材、已存在物品 ID 或确定配方；第一版只选少量材料与配方。

| 掉落示例 | 科技用途示例 | 魔法用途示例 |
| --- | --- | --- |
| 黏液胶质 | 黏胶投掷物、装置黏合剂 | 符文墨水稳定材料 |
| 硬壳碎片 | 护具加固、装置外壳 | 护符载体 |
| 微光晶屑 | 简易照明或装置核心 | 法器与护符材料 |

法术通过学习获得，魔法物品通过配方与材料制作；学会法术不等于自动获得法器，科学／魔法等级提高也不自动发放装备。村庄须提供可实际完成的科技和魔法入门配方，首次引导可任选一件制作，不要求全部完成。

普通敌人提供制作与补给材料，首次制作引导可提供保底材料，不绕过配方等级要求。关键魔法石与普通材料分开：首版工作稿由洞穴底层Boss首次有效击败保底掉落指定魔法石，不用稀有概率反复刷取。魔法石记录自身取得来源，不可购买替代、出售或用于普通配方；已经击败Boss、石门尚未开启却未持有魔法石时，须有经服务端核实的补领或恢复途径，不能要求清空存档重来。开门后已嵌入的魔法石不再补领。

显示材料来源、数量、成品效果与消耗；普通材料提前消耗后可重新取得。伤害、击败、掉落、购买与制作均由服务端确认并保存，同一击败不重复发掉落、购买或制作失败不扣资源、重试不重复发放成品；重复挑战Boss的普通奖励另定，不重复发放唯一魔法石或主线奖励。

战斗奖励主要是游戏内材料、装备与世界进展，不新增知识／健康／技能点来源，也不改变诺亚现实委托及每日合计5点的规则。

### 离村石门与前期成长条件

大石门位于村庄通往外界的共同出口，开启后才进入渡河与翻山路线，修桥和乘船都不能绕开。石门不封锁现有两座村内桥、已开放的生活地点或洞穴入口。

新旅程首次开启须同时满足“本角色已击败指定洞穴Boss、当前持有1枚门钥魔法石、魔法达到3级”，并走近石门主动确认，参数按v1候选待试玩。科技主修也须达到这项最低启门魔法要求，此后仍可主修科技或兼修。石门不是科学与魔法二选一的解法，不再宣称纯科学、魔法0级角色可直接离村。

确认前分别显示魔法石来源与持有状态、当前／所需魔法等级及提升入口。魔法石嵌入、门体永久开启与主线进度由服务端一次结算；任一条件不足或请求失败均不扣石、不改变通行，重复请求不重复消耗。开启后门体有实际变化，长期保留通路，返乡与再次远行不再耗石、查启门等级或重打Boss。已有离村／抵城进度的旧存档不重新封路、撤奖或清空记录，保留补做洞穴教学与石门剧情的入口，具体兼容映射另行验证。

前期成长的用途如下，具体门槛和所需现实时间在平衡阶段确认，不把所有属性都额外堆成一组硬锁：

| 成长方面 | 第一章用途与约束 |
| --- | --- |
| 技能／建造 | 自制武器的硬门槛，也服务自行修桥；购买武器或请村民施工可用金币替代相应制造投入 |
| 知识／科学与魔法 | 科学或魔法等级决定相应武器配方资格；最低启门魔法等级为共同必需条件 |
| 体能／生命与体力 | 支撑洞穴持续探索、Boss战与翻山；v1允许初始100／100配合补给与恢复完成，建议额外投入2健康点，生命／体力上限不另作开门硬条件 |
| 战斗积累 | 在洞穴逐层熟悉战斗并击败指定Boss，取得有来源记录的关键魔法石；不另加无用途的累计击杀次数锁 |
| 金币赚取 | 用于买武器、补给与后续交通／住宿，也可支持自制与施工；展示实际费用，不另加纯累计赚金成就锁 |

知识／健康／技能点继续沿用现实委托来源与每日合计5点上限，因此新离村规则允许现实成长成为首次远行准备的一部分；游戏睡眠、洞穴刷怪与金币交易均不能加速现实委托或兑换这三类点数。未达到离村条件时，村庄生活、经营、现实记录与可承受的洞穴探索仍可继续，界面提供明确缺口与下一步。

v1购买路线最低需3知识点／3小时委托；通用或魔法自制最低4小时，科技自制最低5小时。再加建议的2健康点，分别为5／6／7小时，后两者至少涉及两个北京时间领取日。目标主动游玩45–75分钟与现实委托计时分开，不声称所有路线都必须等两个现实日或一直在线；金币仍处于快速原型经济，详见数值文档的收入与机会成本校核。

### 渡河：建造与乘船两条路径

| 方案 | 条件与投入 | 长期价值 |
| --- | --- | --- |
| 自行修桥 | 明确的材料清单、图纸或修复知识、建造等级 | 一次投入后永久开放，免费往返，桥体有可见变化 |
| 村民协助修桥 | 完成游戏内委托并提供所需材料，由有能力的村民施工 | 不要求玩家先提高建造等级，仍完成同一桥梁修复 |
| 乘船 | 支付船费、帮助船夫或修复旧船取得通行资格 | 较少初期建造投入，可保留班次或单次费用 |

完成洞穴魔法石与魔法等级条件、永久开启石门后，渡河只要求一种有效方案。坐船后仍可回来修桥，不因选择路线失去主线奖励。具体材料、费用、建造等级、班次和帮助船夫的任务内容以任务切片为工作稿，正式平衡待验收；第一章首版先保证桥与船各有一条完整可玩的路径，再扩充分支。

建造门槛约束自主施工，不成为全体玩家的唯一出口。村民协助不额外创造现实成长点数，也不改变现有点数来源。材料交付、施工完成和船费扣除须由服务端确认，失败或重试不能重复扣料、扣费或发奖。

### 翻山：体力、装备与行程

- 当前体力决定能否开始或继续攀登；体力上限影响补给压力和可选路线，两者分别显示。
- 普通山路的当前体力消耗、生命／体力上限与补给要求和洞穴成长一起平衡。v1沿用任务27的初始体力上限100可通过准备完成、翻山消耗当前体力60的旅行候选，不另设健康点或更高上限硬条件。
- 出发前显示所需物品、预计体力消耗、预计抵达时间与已知风险。准备不足时提供明确缺口、补给地点或返回选择，不在途中突然出现未告知的硬性等级锁。
- 山路具有可识别的途中地标与安全折返点；基础步行与对话仍可使用。首次离村的必打Boss安排在指定洞穴，石门开启后山路不随机刷怪，首版不再叠加另一个山路首领或指定装备门槛。
- 首次翻山保留旅程感，之后逐步修复便道、稳定渡船，再考虑驿车。驿车等便捷旅行属于后续独立切片，必须显示时间、费用和目的地，不是地图上的隐式传送。

### 游戏日夜与两种时间

游戏世界采用 24 小时制。通常于 06:00 起床，次日凌晨 01:00 为强制睡眠截止时间；睡眠期间跳转到次日早晨。第一切片沿用原村民时钟的30现实分钟／24游戏小时，19个游戏小时为23分45秒活跃时间；最初25–30分钟的设想仍作为后续试玩调速参考。

| 时间域 | 管理内容 | 暂停与跨日规则 |
| --- | --- | --- |
| 游戏时间 | 已有 NPC 作息与村庄明暗；后续旅程、睡眠、旅馆住宿和生产节奏 | 有效世界游玩时推进；睡眠进入下一游戏日 |
| 现实时间 | 现实委托到期、专注计时、现实活动日期和成长额度 | 沿用服务端计时与 Asia/Shanghai 日期；不被游戏睡眠、暂停或旅行推进 |

离线、页面进入后台、断线而无法确认世界推进、切换 Life Mode 时暂停游戏世界，恢复后不补算离线期间的昏倒。现实委托继续到期，专注计时沿用现有显式暂停规则。暂停不提供移动、采集、制作或攻击机会；时间和状态由服务端维护，不能信任客户端自报经过时长。

非战斗背包、剧情对话等需要阅读的上下文暂停整个世界。当前洞穴战斗中的菜单统一暂停世界、敌人和冷却，不能只暂停日夜而让某一方继续行动。刷新和多标签页不能重置一天或造成重复推进。

游戏睡眠不会刷新现实委托的每日 5 点额度、现实活动奖励上限，也不会缩短现实委托或专注时长。当前村民订单与首次对话奖励仍按现实日结算；以后迁到游戏日时须明确规则和兼容方案，不能顺带扩大现实成长奖励。

### 睡眠、旅馆与昏倒

- 家中床铺免费；旅馆以游戏金币预订并提供可使用的床位。付款前显示费用和适用住宿夜，付款后进出房间不重复收费，支付失败不授予住宿。
- 正常上床结束当天，次日早晨补满体力；首个切片恢复最多20生命，免费短休提供日间补充。食物补给属于后续玩法。
- 夜间分阶段提醒临近 01:00，并提供家或有效旅馆床位的方向。提醒不替代玩家的睡眠操作，路线和住宿状态须如实显示。
- 到 01:00 仍未睡觉则昏倒，下一游戏日早晨回到自己家中，扣除一定当前生命值，不获得当晚睡眠的体力恢复。“不恢复”不等于额外把剩余体力清零。
- 昏倒不降低生命或体力上限，不扣健康点、知识点、技能点及现实成长；该生命扣减不致死。连续昏倒不叠加永久惩罚，也不对离线或错过现实日期处罚。
- 零体力仍可步行、对话和整理，需有可达、低成本的食物或短休恢复途径。抵达城市时提供清楚的旅馆价格和可完成的住宿收入任务，避免身无分文后进入无法恢复的循环。
- 住宿预订扣费独立完成一次权威结算；跨夜时将日期、恢复或昏倒扣血及返家位置一并保存，不再次扣房费。睡眠与截止时间发生竞争、网络重试、刷新或多标签页时，各业务结果只结算一次。

界面统一使用“生命值”表示角色 HP，“体力”表示行动储备，“健康点”表示现实委托成长资源；游戏中昏倒不代表玩家现实健康状况。

### 现有时间规则的过渡

第一切片已把床边立即恢复替换为次日睡眠与短休；每720现实秒自然恢复、作物60秒成熟（小屋2级后新作物45秒）和资源30秒恢复继续有效，相关界面明确说明。睡眠跳过的游戏时间不推进这些现实时间戳。

日夜切片必须一起定义睡眠推进、自然恢复与作物／资源时钟的关系。目标是让世界内生产逐步使用游戏时间、现实成长继续使用现实时间；不把“游戏睡一夜”误算为现实恢复时长，也不让新旧恢复重复发放。迁移须保留已种作物的剩余成熟进度、资源冷却、当前资源、容量、现有建筑效果和委托到期时间，不清空玩家数据。首版恢复途径必须与昏倒规则一起交付；生产时钟迁移若另行交付，应明确标注仍按现实时间运行的内容。

### 科技与魔法：村庄启蒙，城市进阶

现有科学／魔法等级继续使用原字段与知识点规则，设计中的“科技路线”对应现有“科学”等级。能力须获得实际图纸、装备或法术并完成学习／制造后才能使用；等级存在不等于已经拥有能力。

| 方向 | 核心体验 | 发展路径示例 | 非战斗用途 |
| --- | --- | --- | --- |
| 科技 | 预先制造、装备配置与补给管理 | 村庄简易工具／投掷物 → 城市科技武器与改造 → 自动装置／机械伙伴 → 个人驾驶机甲 | 照明、灌溉、采矿、运输 |
| 魔法 | 学习施法、时机判断与效果组合 | 村庄入门法术与护符 → 城市进阶攻击／防护法术与法器 → 更高阶法术 | 点燃炉火、洞穴照明、发现隐藏物、解除封印 |

科学等级主要约束图纸理解、制造与升级，魔法等级主要约束学习与启门；武器打造另须满足建造等级。具体使用按已拥有装备、已学法术、消耗与冷却约束，不把制造资格当作自动获装。村庄从0级提供知识研修入口与可购买的基础武器，实际配方、法术和石门分别展示等级要求。两路线可兼学混用，但首次离村的最低魔法要求适用于所有角色，科技主修也须完成这部分基础研习。

城市阶段通过新图纸、装备改造、法器与进阶法术强化两种风格，复用村庄的战斗、制作与学习规则。两条路线都要能完成同一进阶任务，并分别提供合理的战斗和探索方式；主修与混用均可，不在启门最低魔法要求之外强制双系同步升级。进阶配方和法术可有明确等级门槛，不因进入城市就自动获得；普通生活与住宿保留可继续的入口。个人驾驶机甲及复杂自动战斗放在中后期，不纳入第一章。
