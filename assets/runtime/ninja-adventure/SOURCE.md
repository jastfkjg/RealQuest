# Ninja Adventure source assets

Imported 2026-10-09. Native pixels are never interpolated.

- `tileset.png`: Pixel-boy / Sparklin Labs, [Superpowers Ninja Adventure](https://github.com/sparklinlabs/superpowers-asset-packs/tree/e8674a03ab4456802f71f848c4df79eccca23f7a/ninja-adventure), `background-elements/tileset.png`.
- `character-0.png`, `character-1.png`, `character-2.png`: same source; original files `characters/14.png`, `characters/2.png`, `characters/1.png`. Each sheet is 64×112 with four direction columns and four walking rows; remaining action rows are unused.
- `village.png`: Pixel-boy (Ninja Adventure), [artist's repository](https://github.com/pixel-boy/NinjaAdventure/tree/6ac78232d5aedcc85ce5f27d060ea92366f7c24a/content/map), `tileset_village_abandoned.png`. [Official license statement](https://pixel-boy.itch.io/ninja-adventure-asset-pack): CC0; commercial use allowed.
- `house-home.png`, `house-library.png`: cropped, masked and palette-adjusted derivatives of `village.png`; generated by `frontend/scripts/build-village-assets.py`.
- `LICENSE.txt`: CC0-1.0 from the Superpowers repository. Both sources explicitly use CC0. Attribution is voluntary; retained here for provenance.

Only the listed sheets are packaged. No original reference-game artwork, music or fonts is distributed.

- `icons/wood.png`: cropped CC0 tileset fragment. `icons/stone.png`, `gold.png`, `seed.png`, `crop.png`, `plank.png`: original RealQuest pixel icons generated by the same build script; governed by the project license rather than the source pack notice.

## Welcome appearance expansion — 2026-10-10

`character-3.png`, `character-4.png`, `character-5.png` are byte-identical copies of `characters/6.png`, `characters/9.png`, `characters/5.png` from the same fixed Superpowers commit above. 64×112 sheets, 16×16 cells; four walking rows audited visually and exercised in all four directions. Original IDs 0–2 unchanged. Source originals, license and provenance are retained under `assets/vendor/ninja-adventure/characters/`; hashes and bindings are recorded in `docs/art/asset-manifest.json`. Cosmetic choices only; no attribute modifiers.
